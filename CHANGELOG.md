# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-11-20

### Added
- **Interactive Deal Kanban board and Pipeline Settings (S2.3)**: Added drag-and-drop and keyboard-accessible `DealKanbanBoard`, `SettingsPipelinesSection` (rename pipeline, add/edit/reorder/delete stages with 10 tone badges and Deal reassignment modal), dynamic **Pipelines** Settings tab gating when `Deal` is enabled, and pipeline API helpers (`07c0ef2`, `0b51480`, `d1a59ed`, `8cb497c`, `dd612bc`, `26f5f6e`; `src/components/crm/DealKanbanBoard.jsx`, `src/components/SettingsPipelinesSection.jsx`, `src/screens/DealsPane.jsx`, `src/screens/SettingsPane.jsx`, `src/service/crmService.js`, `src/utils/catalog.js`).
- **Role cloning, field permissions, record sharing, and live permission sync (S2.4)**: Added role cloning, editing, deletion, per-object field rights (`hidden`/`read_only`/`editable`) and 7 capability switches in `SettingsRolesSection`, invite and member role assignment in `SettingsPeopleSection`, `RecordSharingControl` and `FieldLabel` across all CRM panes and inspectors, initial password setup and passkey renaming in `SettingsPane`, and live `X-Permissions-Version` synchronization with automatic refresh and toast notification in `App.jsx` (`07c0ef2`, `b1463c5`, `8cb497c`, `381670a`, `dd612bc`, `26f5f6e`; `src/App.jsx`, `src/components/SettingsRolesSection.jsx`, `src/components/SettingsPeopleSection.jsx`, `src/components/crm/RecordSharingControl.jsx`, `src/components/crm/FieldLabel.jsx`, `src/screens/SettingsPane.jsx`, `src/utils/api.js`, `src/utils/crmFormOptions.js`).
- **Global Search bar with quick navigation and quick create (S2.5, S2.8)**: Added centered topbar `GlobalSearchBar` (`Ctrl/Cmd+K`, mobile expand support, keyboard navigation, pack- and permission-aware object filter pills, paginated results, quick-nav, and quick-create actions) (`a77839b`, `f770d6c`, `8dc6704`, `46e47a5`; `src/components/GlobalSearchBar.jsx`, `src/screens/WorkspaceShell.jsx`, `src/index.css`).
- **Paginated relation picker, URL deep linking, and Audit Change History (S2.5)**: Added server-backed searchable/paginated `RecordRelationPicker` wired across CRM panes and `ConvertLeadModal`, `?inspect=<id>` URL deep linking with browser history support, enhanced `AuditLogDrawer` filters (`actor_kind`, `object_type`, `action`, `q`) with record Inspect links, and per-record `RecordAuditHistory` in `RecordInspectorDrawer` (`a77839b`, `f770d6c`, `747548f`, `8dc6704`, `1f7b01b`, `1643301`; `src/components/crm/RecordRelationPicker.jsx`, `src/components/AuditLogDrawer.jsx`, `src/components/crm/RecordAuditHistory.jsx`, `src/components/crm/RecordInspectorDrawer.jsx`, `src/components/crm/ConvertLeadModal.jsx`, `src/App.jsx`, `src/hooks/useCrmRecordsPane.js`).
- **Visits screen for Healthcare workspaces (S2.6)**: Added `VisitsPane` with Patient (`RecordRelationPicker`), Follow-up, Assignee, and Sharing filters, create modal, and record inspector with S2.4 CRUD and field-right enforcement (`a77839b`, `747548f`, `8dc6704`, `1643301`; `src/screens/VisitsPane.jsx`, `src/screens/WorkspaceShell.jsx`, `src/utils/catalog.js`).
- **Client-side cache and request deduplication (S2.7)**: Added `clientCache` with workspace-scoped TTL caching, in-flight request deduplication, automatic mutation invalidation, and lazy-loaded route screens in `App.jsx` (`a4ec62f`, `1b48459`; `src/utils/clientCache.js`, `src/utils/api.js`, `src/service/crmService.js`, `src/App.jsx`, `src/screens/DashboardPane.jsx`, `src/screens/SignupScreen.jsx`, `src/components/SettingsPacksSection.jsx`, `src/components/SettingsPipelinesSection.jsx`, `src/components/SettingsRolesSection.jsx`).
- **Bento Dashboard analytics components (S2.8)**: Refactored `DashboardPane` into modular Bento metric components (`DashboardKpiRow`, `DashboardVelocityBento`, `DashboardBottomBento`) displaying KPI summaries, velocity trends, and Ghana regional hub insights (`16d8027`; `src/screens/DashboardPane.jsx`, `src/components/dashboard/DashboardKpiRow.jsx`, `src/components/dashboard/DashboardVelocityBento.jsx`, `src/components/dashboard/DashboardBottomBento.jsx`, `src/screens/WorkspaceShell.jsx`).

### Fixed
- **Role clone source and Lead conversion field rights**: Fixed role cloning source selection in `SettingsRolesSection` and enforced field-level visibility/read-only rules in `ConvertLeadModal` and `RecordLinksSection` (`5d9e6e1`; `src/components/SettingsRolesSection.jsx`, `src/components/crm/ConvertLeadModal.jsx`, `src/components/crm/RecordLinksSection.jsx`).

### Documentation & Maintenance
- **Changelog, product specs, and unit tests**: Added `CHANGELOG.md`, synced `docs/PRD.md`, `docs/SCOPE.md`, and `docs/BACKLOG.md`, and added unit tests for `clientCache` (`1fe45ea`, `c9d056a`, `77ee11f`, `0160408`; `src/utils/clientCache.test.mjs`).

## [1.0.0] - 2026-11-17

### Breaking Changes
- **Replaced Vite starter application**: Removed `src/App.css`, `src/assets/hero.png`, `src/assets/react.svg`, and `src/assets/vite.svg`, and replaced the starter counter page and CSS with the jojoCRM SPA, custom design tokens, and workspace URL routing (`a4b94c0`, `e919263`, `a175d0f`; `index.html`, `src/App.jsx`, `src/index.css`, `src/main.jsx`).
- **Backend API dev proxy coupling**: Configured Vite dev server on port `5173` to proxy `/api` requests to `http://127.0.0.1:8000` (`a4b94c0`; `vite.config.js`).

### Added
- **Design system and reusable UI primitives**: Configured Tailwind CSS (`tailwindcss`, `postcss`, `autoprefixer`), light/dark theme persistence (`jojocrm_theme`), and shared components (`Button`, `Card`, `Checkbox`, `Drawer`, `Modal`, `Select`, `Subtabs`, `FeedbackNotice`, `AuthCardShell`, `ThemeToggleButton`, `RefreshButton`, `CrmTooltipLayer`) (`a4b94c0`, `e919263`, `a96c314`, `9ffed21`, `dd4aaed`; `tailwind.config.js`, `postcss.config.js`, `src/index.css`, `src/utils/theme.js`, `src/components/`).
- **Authentication, invite acceptance, and session recovery screens**: Added `/signup` (with 20-business-type selector and 17-table preview), `/login` (password, Google, Microsoft, and WebAuthn passkeys), `/verify-email`, `/forgot-password`, `/reset-password`, `/accept-invite` (with IANA timezone selection), closed-workspace verification gates, and CSRF/deduplicated API helpers (`e919263`, `a175d0f`, `40d29a4`, `67bd86a`; `src/App.jsx`, `src/screens/`, `src/utils/api.js`, `src/utils/webauthn.js`, `src/utils/timezones.js`).
- **Dynamic workspace shell, Settings, and Audit Log drawer**: Added hover-expanding sidebar navigation driven by `enabled_object_keys` and adapted Contact labels, URL pane/subtab persistence (`/{slug}/{pane}/{subtab}`), disabled-module and future-sprint directory previews, the `36rem` `AuditLogDrawer`, and `SettingsPane` covering **Workspace**, **Packs**, **People**, **Roles** (with interactive per-object CRUD permissions matrix), and **Account & Security** (`a96c314`, `a175d0f`, `67bd86a`, `dd4aaed`; `src/screens/WorkspaceShell.jsx`, `src/screens/SettingsPane.jsx`, `src/components/Settings*.jsx`, `src/components/AuditLogDrawer.jsx`, `src/utils/catalog.js`).
- **Live CRM dashboard, record panes, inspector drawer, and activities**: Added `crmService`, `useCrmRecordsPane`, tabular GHS and timezone-aware formatters, `CrmListPage`, `PaginationBar`, `RecordInspectorDrawer`, `RecordLinksSection`, `ActivityTimeline` (inline quick-composer, edits, completion toggles, and >100-item overflow notice), mini distribution charts (`SummaryMiniCharts`, `PipelineStageDistribution`), and wired `DashboardPane`, `AccountsPane`, `ContactsPane`, `LeadsPane`, `DealsPane` (Table and read-only Stage Board views), `JobsPane`, `AppointmentsPane`, and `TicketsPane` (`40d29a4`, `9ffed21`, `7591ab1`; `src/service/crmService.js`, `src/hooks/useCrmRecordsPane.js`, `src/components/crm/`, `src/screens/`, `src/utils/formatters.js`, `src/utils/crmFormOptions.js`).
- **Lead-to-Deal conversion workflow**: Added `ConvertLeadModal` (server-backed Lead search picker, Account/Contact match banners with Create vs Reuse options and search fallback, Deal creation fields), `ConversionResultBanner` with direct record links, `canUserConvertLead` gating, and conversion actions plus provenance tags across Leads, Deals, Accounts, and Contacts (`0b93a55`, `d50de63`; `src/components/crm/ConvertLeadModal.jsx`, `src/components/crm/ConversionResultBanner.jsx`, `src/components/crm/RecordLinksSection.jsx`, `src/screens/LeadsPane.jsx`, `src/screens/DealsPane.jsx`, `src/screens/AccountsPane.jsx`, `src/screens/ContactsPane.jsx`, `src/service/crmService.js`).

### Changed
- **Checkbox styling consistency**: Replaced native browser checkboxes in `SettingsRolesSection` and `ActivityTimeline` with the custom frosted `Checkbox` component (`dd4aaed`; `src/components/Checkbox.jsx`, `src/index.css`).

### Documentation & Maintenance
- **UI template, startup guide, and product docs**: Added `UI-template/jojocrm_workspace_ui.html`, updated `README.md` with local API/Vite startup steps and `Checkbox` usage notes, added `docs/PRD.md`, `docs/SCOPE.md`, `docs/SOW.md`, and `docs/BACKLOG.md`, and added `.env`, `.agent/*`, and `.cursor/*` to `.gitignore` (`a4b94c0`, `3d22e78`, `9450e65`, `dd4aaed`).

### Upgrade & Deployment Notes
- **Dependencies and API server**: Run `npm install` to install `tailwindcss`, `postcss`, and `autoprefixer`, and ensure the `jojoCRM` backend server is running at `http://127.0.0.1:8000` before starting `npm run dev` on `http://localhost:5173`.
- **Manifest version alignment**: `package.json` on `alpha` still carries `"version": "0.0.0"`; update it to `1.0.0` (or your chosen release tag) when cutting a release.
